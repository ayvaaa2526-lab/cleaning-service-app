# Clearly Cleaning

Standalone multilingual cleaning quote calculator.

## Features
- Russian, English and Georgian
- GEL / USD display
- Cleaning types and extras
- Client details, discounts and quote validity
- Local quote history
- Browser Print / Save as PDF
- Responsive mobile UI

## Deploy
This is a static application. Upload all files to any static host or connect this repository to Cloudflare.

> Note: the USD conversion rate in `app.js` is currently a configurable fixed demo rate (2.7 GEL = 1 USD). Replace it with the desired business rate or an exchange-rate API before production use.
